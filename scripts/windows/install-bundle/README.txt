OneTap Habits — Windows install
================================

Requirements: Windows 10 (1809+) or Windows 11.

Quick install
-------------
1. Extract this ZIP to a folder (e.g. Downloads\OneTapHabits).
2. Double-click Install.cmd (accept the UAC prompt).
3. Open "OneTap Habits" from the Start menu.

If install fails with a certificate error, right-click Install.cmd and choose Run as administrator.

Uninstall
---------
Settings → Apps → Installed apps → OneTap Habits → Uninstall
